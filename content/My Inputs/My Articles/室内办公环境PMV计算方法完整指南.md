# 室内办公环境PMV计算方法完整指南

PMV（预测平均投票数）是评估办公环境热舒适度的核心指标，本报告提供从理论到实践的全面指导，帮助工程师准确计算和评估室内办公环境的热舒适性。

## PMV计算的完整公式与参数说明

### 核心计算公式

PMV的计算基于人体热平衡方程，完整公式如下：

**PMV = [0.303 × exp(-0.036 × M) + 0.028] × L**

其中L（热负荷）的详细计算式为：

**L = (M-W) - 3.05×10⁻³×[5733 - 6.99×(M-W) - pa] - 0.42×[(M-W) - 58.15] - 1.7×10⁻⁵×M×(5867 - pa) - 0.0014×M×(34 - ta) - 3.96×10⁻⁸×fcl×[(tcl+273)⁴ - (tr+273)⁴] - fcl×hc×(tcl - ta)**

### 六个核心参数详解

计算PMV需要准确获取以下六个参数：

1. **空气温度（ta）**：环境干球温度，单位°C，典型范围10-30°C
2. **平均辐射温度（tr）**：围护结构表面辐射温度的加权平均值，单位°C
3. **相对湿度（RH）**：空气相对湿度，百分比形式，需转换为水蒸气分压力
4. **空气流速（var）**：人体周围空气流速，单位m/s，典型范围0-1.0m/s
5. **代谢率（M）**：人体内部产热率，单位W/m²或met（1 met = 58.2 W/m²）
6. **服装热阻（Icl）**：服装的隔热性能，单位m²·K/W或clo（1 clo = 0.155 m²·K/W）

## 利用温度和湿度数据计算PMV

### 相对湿度转换为水蒸气分压力

PMV公式中需要水蒸气分压力pa，通过以下步骤从相对湿度转换：

1. 计算饱和水蒸气分压力：**ps = 611.21 × exp(17.625 × ta/(243.04 + ta))**
2. 计算实际水蒸气分压力：**pa = RH × ps / 100**

### 辅助参数计算

服装表面积系数（fcl）：

- 当 Icl ≤ 0.078 m²·K/W 时：fcl = 1.00 + 1.290×Icl
- 当 Icl > 0.078 m²·K/W 时：fcl = 1.05 + 0.645×Icl

对流换热系数（hc）取以下两式的较大值：

- hc = 2.38×|tcl - ta|⁰·²⁵
- hc = 12.1×√var

服装表面温度（tcl）需通过迭代求解。

## 室内办公环境的典型参数设置

### 代谢率标准值

办公环境中人员活动的典型代谢率：

- **静坐办公**：1.0 met（58.2 W/m²）
- **轻度办公活动**：1.2 met（70 W/m²）- 推荐标准值
- **站立工作**：1.2 met（70 W/m²）
- **轻度走动**：1.6 met（93 W/m²）

### 服装热阻典型值

不同季节办公着装的热阻值：

- **夏季轻薄着装**：0.5-0.7 clo（短袖衬衫、薄长裤）
- **春秋标准着装**：0.8-1.0 clo（长袖衬衫、西裤）
- **冬季正装**：1.0-1.2 clo（西装、衬衫、内衣）

### 空气流速标准假设

办公室环境的典型风速：

- **标准空调办公室**：0.1 m/s（推荐值）
- **自然通风办公室**：0.1-0.3 m/s
- **强制通风区域**：0.15-0.25 m/s

### 平均辐射温度估算方法

在实际应用中，平均辐射温度的估算有以下几种方法：

1. **简化假设**：tr ≈ ta（当围护结构热工性能良好时）
2. **黑球温度法**：使用黑球温度计测量，通过公式换算
3. **表面温度法**：测量各表面温度，按面积加权平均
4. **经验修正**：夏季tr = ta + (0-2)°C；冬季tr = ta + (-2-0)°C

## 具体计算步骤和实用工具

### 计算流程

1. **数据收集**：测量或估算六个核心参数
2. **单位转换**：确保所有参数单位正确（met转W/m²，clo转m²·K/W，%RH转Pa）
3. **迭代计算**：求解服装表面温度tcl
4. **PMV计算**：应用Fanger公式计算PMV值
5. **PPD计算**：PPD = 100 - 95×exp(-0.03353×PMV⁴ - 0.2179×PMV²)

## PMV值的解释和舒适度评价标准

### PMV七级热感觉尺度

PMV值范围从-3到+3，对应不同的热感觉：

- **+3**：热
- **+2**：暖
- **+1**：稍暖
- **0**：中性（最舒适）
- **-1**：稍凉
- **-2**：凉
- **-3**：冷

### 舒适度评价标准

根据不同的应用场景，采用不同的PMV范围：

- **高标准舒适度**：PMV = -0.3 ~ +0.3，PPD ≤ 7%（95%人员满意）
- **标准舒适度**：PMV = -0.5 ~ +0.5，PPD ≤ 10%（90%人员满意）
- **基本舒适度**：PMV = -0.8 ~ +0.8，PPD ≤ 20%（80%人员满意）

## 中文语境下的相关标准

### 中国国家标准

1. **GB/T 18049-2017**《热环境的人类工效学 通过计算PMV和PPD指数与局部热舒适准则对热舒适进行分析测定与解释》
    
    - 等同采用ISO 7730:2005标准
    - 提供详细的PMV计算方法和评价准则
2. **GB/T 50785-2012**《民用建筑室内热湿环境评价标准》
    
    - 规定了不同类型建筑的热舒适要求
    - 提供了测量和评价方法
3. **GB 50736-2012**《民用建筑供暖通风与空气调节设计规范》
    
    - 在设计参数中引用PMV评价方法
    - 适用于新建、改建和扩建民用建筑

### 应用要点

中国标准基本与国际标准保持一致，推荐PMV控制在-0.5到+0.5之间。在实际应用中，需考虑地域气候差异和人群适应性特征。

## 实际应用中的简化计算方法

### 快速估算法

当其他参数接近标准值时，可使用以下经验规则：

- **温度调整**：空气温度每变化1°C，PMV约变化0.3
- **服装调整**：服装热阻每变化0.1 clo，相当于温度变化0.6°C
- **湿度影响**：相对湿度在30%-70%范围内，对PMV影响较小（约0.1-0.2）

使用VBA宏或连接Python脚本实现自动计算。
