## Note Types

USV 库中使用的笔记类型分类。

### 常见类型

- **Input 笔记** — 文章、书籍、播客、视频的阅读/观看笔记
- **Note 笔记** — 知识卡片、常青笔记（Evergreen Notes）
- **Thought 笔记** — 随想、灵感
- **Meeting 笔记** — 会议记录
- **Project 笔记** — 项目管理
- **MOC 笔记** — 知识地图（Map of Content）
- **View 笔记** — 仪表盘视图
- **Person 笔记** — 人物档案
