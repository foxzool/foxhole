## Windows
```powershell
@(Get-CimInstance -Namespace root\wmi -ClassName WmiMonitorBasicDisplayParams).Length` is a pure PowerShell solution.
```
If you want to filter it to only active displays, then 
```powershell
@(Get-CimInstance -Namespace root\wmi -ClassName WmiMonitorBasicDisplayParams | where-object { $_.Active }).Length`.
```

## Linux
```bash
xrandr -d :0 -q | grep ' connected' | wc -l
```

```bash
xrandr --listmonitors | grep Monitors | awk '{print $2}'
```
